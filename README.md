# 📍 GLA Routes

## 📖 Overview

GLA Routes is an Android-based navigation application designed to help students, visitors, and faculty easily navigate across the GLA University campus. It provides accurate location guidance, 360° views, and essential campus services in one place.

---

##  Features

*  **Campus Navigation** – Find routes from current location to any block
*  **Google Maps Integration** – Real-time directions
*  **User Authentication** – Secure login using Firebase
*  **360° View** – Visual representation of locations
*  **Ride Booking** – Book rides within campus
*  **User Data Storage** – Managed via Firebase database

---

## 🛠️ Tech Stack

* **Frontend:** Android (Java, XML)
* **Backend:** Firebase
* **APIs:** Google Maps API
* **IDE:** Android Studio

---

## 📱 How to Run the Project

1. Clone the repository:

   ```bash
   git clone https://github.com/your-username/GLARoutes-G35.git
   ```

2. Open in Android Studio

3. Add your Firebase configuration (`google-services.json`)

4. Run the app on emulator or device
